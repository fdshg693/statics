# RPGゲームシステム仕様書（vue_rpg）

本ドキュメントは、ターン制バトルRPG『vue_rpg』のゲームコアシステム、戦闘システム、パラメータ計算式、成長仕様、ドロップシステムなどの詳細な仕様を解説するものです。

---

## 1. 概要
本ゲームは、プレイヤーである「勇者」が各階層（フロア）で遭遇する敵と戦い、勝利を重ねてより深層を目指すターン制バトルRPGです。戦闘で獲得した経験値による成長、ドロップした装備や回復薬のインベントリ管理、および進捗状況のセーブ・ロードに対応しています。

---

## 2. プレイヤーのステータスと成長システム

### 2.1 初期ステータス（レベル1）
プレイヤーの初期状態は以下の通り設定されています。

| パラメータ | 初期値 | 説明 |
| :--- | :--- | :--- |
| **名前** | 勇者 | プレイヤーキャラクター名 |
| **レベル (Level)** | 1 | プレイヤーの現在のレベル |
| **HP (Hit Points)** | 100 / 100 | 生命力。0になると戦闘敗北（ゲームオーバー） |
| **MP (Magic Points)** | 30 / 30 | 魔法力。スキル（アクション）を使用する際に消費 |
| **攻撃力 (Attack)** | 20 | 与えるダメージの基礎値 |
| **防御力 (Defense)** | 10 | 受けるダメージを減らす基礎値 |
| **経験値 (Exp)** | 0 | 敵を倒すことで獲得するポイント |
| **次レベルへの必要経験値** | 100 | レベルアップに必要な経験値（初期値） |
| **インベントリ (Inventory)**| 空 | 武器、ポーション、ゴールド（初期値は0G）を保持 |

### 2.2 レベルアップ仕様
所持経験値（`Exp`）が「次レベルへの必要経験値（`expToNextLevel`）」に達した時点で自動的にレベルアップします。

* **ステータス成長量（固定値）**
  * 最大HP：`+10`
  * 最大MP：`+5`
  * 攻撃力：`+3`
  * 防御力：`+2`
  * **全回復効果**：レベルアップと同時に、HPおよびMPがそれぞれの新しい最大値まで**完全回復**します。
* **経験値のリセットと必要量の上昇**
  * レベルアップすると、所持経験値は `0` にリセットされます。
  * 次のレベルまでに必要な経験値は、前回の必要値に**1.5倍（端数切り捨て）**を掛けた値に上昇します。
    * *例：Lv1→Lv2: 100 EXP / Lv2→Lv3: 150 EXP / Lv3→Lv4: 225 EXP*

## 3. 戦闘システム（バトルメカニクス）

### 3.1 バトルステート（状態遷移）
戦闘は以下の4つの状態で管理されます。
1. **`idle` (待機中)**: 戦闘が発生していない状態。非戦闘中のポーション使用や、新規戦闘の開始、スタート画面への帰還が可能です。
2. **`fighting` (戦闘中)**: プレイヤーと敵が交互に行動を行う状態。
3. **`victory` (戦闘勝利)**: 敵のHPを0にした状態。経験値およびアイテム・ゴールドの獲得処理が行われます。
4. **`defeat` (戦闘敗北)**: プレイヤーのHPが0になった状態。一定時間経過後、自動的にスタート画面へと強制遷移されます。

### 3.2 プレイヤーのアクション（コマンド）
プレイヤーは自分のターンに以下のコマンドを実行できます。各コマンドには消費MPが設定されています。

| コマンド | 消費MP | アクション内容と効果 |
| :--- | :--- | :--- |
| **通常攻撃** | `0` | 敵へ通常攻撃を実行します。 |
| **回復 (ヒール)** | `8` | 呪文によって自身の傷を癒やします。効果：**最大HPの30%（端数切り捨て）を回復**。 |
| **防御 (ガード)** | `4` | 身を護る姿勢をとります。効果：**このターン（敵の次の攻撃）に受けるダメージを50%軽減**。 |
| **逃走 (エスケープ)**| `6` | 戦闘から離脱を試みます。効果：**50%の確率で成功**。成功時は `idle` に遷移し敵が消失。失敗時は敵のターンへ移行。 |

> [!NOTE]
> MPが不足しているアクションは実行できません。また、非戦闘時であってもインベントリ内の「ポーション」を使用することは可能です（非戦闘時の使用はMPを消費せず、ターンも経過しません）。

### 3.3 ダメージ計算式
プレイヤーと敵の双方が攻撃する際、以下の計算式で最終ダメージが算出されます。

$$\text{基本ダメージ} = \text{攻撃側の攻撃力} - \frac{\text{防御側の防御力}}{2}$$

$$\text{最終ダメージ} = \lfloor \text{基本ダメージ} \times \text{乱数因子} \times \text{防御補正} \rfloor$$

* **乱数因子**: `0.8` 〜 `1.2` の範囲からランダムに決定されます（ダメージの±20%の揺らぎ）。
* **防御補正**: 対象が「防御」コマンドを実行中の場合は `0.5`（50%軽減）、それ以外は `1.0`。
* **最小ダメージ保証**: 計算結果が0以下になった場合であっても、必ず最低 `1` のダメージを与えます。

## 4. 敵キャラクターシステム

敵キャラクターは、ベースとなるテンプレートデータを基準に、現在の「階層」および「敵のタイプ（レア度）」によって強さと報酬が補正されます。

### 4.1 敵テンプレート一覧
ゲームに登場する基本テンプレートは以下の5種です。

| 名前 | 出現Lv | 基礎HP | 基礎攻撃力 | 基礎防御力 | 基礎EXP倍率 | 出現頻度（比率） | 成長率 (Lvごと) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **スライム** | 1 | 30 | 8 | 3 | 10 | 50 (52.6%) | HP+5, ATK+1, DEF+0.5 |
| **ゴブリン** | 2 | 50 | 12 | 5 | 15 | 30 (31.6%) | HP+8, ATK+2, DEF+1 |
| **オーク** | 3 | 80 | 18 | 8 | 15 | 15 (15.8%) | HP+12, ATK+3, DEF+1.5 |
| **トロール** | 4 | 120 | 25 | 12 | 20 | 8 (8.4%) | HP+18, ATK+4, DEF+2 |
| **ドラゴン** | 5 | 200 | 35 | 20 | 20 | 2 (2.1%) | HP+30, ATK+6, DEF+3 |

### 4.2 敵レベルの決定
出現する敵のレベルは、プレイヤーが探索している現在の階層（`floor`）に基づいて決定されます。

$$\text{敵のレベル} = \max(1, \text{現在の階層} + \text{ランダム偏差})$$
* **ランダム偏差**: `-1`, `0`, `1`, `2` のいずれかが等確率で選択されます。

### 4.3 敵ステータスの計算
決定された「敵レベル」を基に、以下の式でレベル補正ステータスが計算されます。

$$\text{レベル補正HP} = \text{基礎HP} + (\text{HP成長率} \times \text{敵レベル})$$
$$\text{レベル補正攻撃力} = \text{基礎攻撃力} + (\text{攻撃成長率} \times \text{敵レベル})$$
$$\text{レベル補正防御力} = \text{基礎防御力} + (\text{防御成長率} \times \text{敵レベル})$$

### 4.4 敵のタイプ（レア度）と能力補正
敵が出現する際、確率によって以下の3つのタイプのいずれかに分類されます。タイプに応じてステータスと獲得経験値に強力な乗算補正が適用されます。

| タイプ | 出現確率 | 名前の変化 | 能力値・報酬補正 |
| :--- | :---: | :--- | :---: |
| **ボス (boss)** | `2%` | `[ベース名]・ザ・ボス` | **`2.0倍`** |
| **リーダー (leader)**| `13%` | `リーダー[ベース名]` | **`1.5倍`** |
| **通常 (normal)** | `85%` | 変化なし | **`1.0倍`** |

* *例：2階でレベル2の「リーダーゴブリン」が出現した場合、補正後のHPは `(50 + 8 * 2) * 1.5 = 99` となります。*

### 4.5 獲得経験値の計算
戦闘勝利時に獲得できる経験値は、以下の式で算出されます。

$$\text{獲得経験値} = \lfloor \text{敵テンプレートの出現Lv} \times \text{基礎EXP倍率} \times \text{タイプ補正} \rfloor$$
* ボスならタイプ補正 `2.0`、リーダーなら `1.5`、通常なら `1.0`。

## 5. アイテム＆ドロップシステム

敵を倒すと、ゴールドは必ず獲得でき、さらに確率で「武器（Weapon）」や「ポーション（Potion）」が手に入ります。

### 5.1 ゴールドのドロップ
獲得できるゴールド額は、現在の階層と敵のタイプによって以下のように計算されます。

$$\text{基礎ゴールド} = 10 + (\text{現在の階層} \times 5)$$

$$\text{獲得ゴールド} = \lfloor \text{基礎ゴールド} \times \text{敵タイプ倍率} \times \text{ランダム要素} \rfloor$$

* **敵タイプ倍率**: ボスは `2.5倍`（$2.0 \times 1.25$）、リーダーは `1.5倍`、通常は `1.0倍`。
* **ランダム要素**: `0.7` 〜 `1.3` の範囲で変動します（±30%のランダム偏差）。

### 5.2 武器・ポーションのドロップ確率
敵のタイプが強力であるほど、アイテムのドロップ確率が高くなります。

| アイテム種別 | 通常（敵タイプ） | リーダー（敵タイプ） | ボス（敵タイプ） |
| :--- | :---: | :---: | :---: |
| **武器 (Weapon)** | `15%` | `40%` | `80%` |
| **ポーション (Potion)** | `25%` | `50%` | `70%` |

### 5.3 ドロップアイテムのレアリティ決定
ドロップが確定したアイテムには、確率によってレアリティ（全5段階）が割り当てられます。強敵ほど高レアリティのものがドロップしやすくなります。

| 敵のタイプ | common (通常) | uncommon (上級) | rare (レア) | epic (史詩) | legendary (伝説) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **通常** | `90%` | `9%` | `1%` | `0%` | `0%` |
| **リーダー** | `50%` | `30%` | `15%` | `5%` | `0%` |
| **ボス** | `15%` | `25%` | `30%` | `20%` | `10%` |

### 5.4 武器の性能（攻撃力ボーナス）
入手した武器は、インベントリに格納されるとプレイヤーの攻撃力にボーナスが加算されます。
強さは現在の階層とレアリティによって以下のように決定されます。

$$\text{基礎ボーナス} = 2 + \lfloor \text{現在の階層} \times 0.5 \rfloor$$

$$\text{武器攻撃力加算} = \text{基礎ボーナス} \times \text{レアリティ倍率}$$

| レアリティ | 武器名（例） | レアリティ倍率 |
| :--- | :--- | :---: |
| **common** | 鉄の剣 | `1.0` |
| **uncommon**| 鋼の剣 | `1.5` |
| **rare** | 銀の剣 | `2.5` |
| **epic** | 魔剣 | `3.5` |
| **legendary**| 伝説の剣 | `5.0` |

### 5.5 ポーションの性能（HP回復量）
インベントリから使用してHPを固定値回復します（最大HPを超えて回復することはありません）。
回復量は階層とレアリティにより以下のように決定されます。

$$\text{基礎回復量} = 20 + (\text{現在の階層} \times 2)$$

$$\text{ポーション回復量} = \text{基礎回復量} \times \text{レアリティ倍率}$$

| レアリティ | ポーション名 | レアリティ倍率 |
| :--- | :--- | :---: |
| **common** | 初級ポーション | `1.0` |
| **uncommon**| 中級ポーション | `1.5` |
| **rare** | 上級ポーション | `2.5` |
| **epic** | 高級ポーション | `3.5` |
| **legendary**| 万能薬 | `5.0` |

## 6. 階層（フロア）進行システム

* **フロア上昇条件**: 現在の階層で**3回**戦闘をクリアすると、次の階層へ進みます。
  * 勝利、もしくは「逃走成功」のどちらでも戦闘回数としてカウントされます。
  * 3回に達した時点で自動的に `floor` が `+1` され、そのフロアでの戦闘カウントは `0` に戻ります。
* **フロア上昇の影響**:
  * 出現する敵のレベル帯が上昇し、強くなります。
  * 敵撃破時に獲得できるゴールドの基礎額が増加します。
  * ドロップする武器の攻撃力ボーナスおよびポーションの回復量が増加します。

## 7. セーブ・ロードシステム

本ゲームは `localStorage` を利用した複数セーブスロット方式のセーブ履歴管理システムを採用しています。

### 7.1 ストレージキー
ローカルストレージ内で以下の3つのキーを使用して状態を永続化しています。

* **`rpg_battle_game_saves`**: セーブスロット全体の情報を保持するJSON配列。
* **`rpg_battle_game_active_save_id`**: 現在読み込んでいる（または現在上書き対象となっている）アクティブなセーブスロットのID。
* **`rpg_battle_game_save`**（レガシー）: 古いバージョンで使用されていた単一セーブスロット用のキー。ロード時にこのキーが存在する場合、自動的に新方式へマイグレーションされます。

### 7.2 セーブデータの構成 (`SaveEntry`)
各セーブスロットは以下の構造で管理されます。
```typescript
interface SaveEntry {
    id: string;        // ユニークID ("save_[時間]_ランダム文字")
    label: string;     // 表示用ラベル ("レベル[X] / [Y]階")
    createdAt: number; // 作成時のタイムスタンプ
    updatedAt: number; // 最終更新時のタイムスタンプ
    state: GameState;  // ゲームの全状態データ
}
```

### 7.3 保存のタイミング
* **自動保存 (Auto-Save)**:
  * プレイヤーの「HP変更」「MP変更」「戦闘状態 (`battleState`) の変化」をVueのリアクティブ監視システムで監視しており、これらの変化が発生するたびにアクティブなセーブスロットへ自動で上書き保存されます。
  * *例外*: プレイヤーのHPが0になった（または敗北状態 `defeat` の）場合は、自動保存はスキップされます。
* **手動保存 (スナップショット作成)**:
  * バトル画面から「記録してスタート画面へ戻る」ボタンを押した際、現在の状態が**新しいセーブスロットとして新規作成（複製保存）**され、セーブ履歴の最上位に追加されます。
