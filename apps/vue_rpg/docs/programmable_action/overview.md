# プログラマブルアクション: 概要と公開API仕様

このドキュメントでは、バトル中の自動行動決定（プログラマブルアクション）の全体概要、主要コンセプト、およびスクリプト内で利用可能な公開API仕様について説明します。

---

## 概要

プログラマブルアクションは、プレイヤーが事前に記述したJavaScriptスクリプトによって、戦闘中の行動を自動的に決定できる仕組みです。
通常のUI（攻撃・魔法・防御などのボタン）による操作性を損なうことなく、プレイヤー状態や敵の状態に応じた柔軟かつ自律的な行動（インテリジェントオートバトル）を実現します。

---

## 主要コンセプト

### 1. 安全な状態へのアクセス（スナップショット評価）
スクリプト実行時、ゲームの書き換え可能な内部状態（ゲームインスタンス）には直接アクセスできません。
ターン開始時点におけるゲーム状態を「読み取り専用のスナップショット」としてクローン・フリーズしたオブジェクトのみがスクリプト側に提供されます。これにより、意図しない状態改ざんを防ぎます。

### 2. 非破壊的フォールバック（透過的協調）
スクリプトの実行に失敗した場合（文法エラーや実行時エラー）、またはスクリプトが明確な行動決定を下さなかった（コマンドを発行しなかった）場合は、自動的に通常のUI入力待ちへとフォールバックします。ゲームの進行が停止することはありません。

### 3. 1ターン・1アクション制約
スクリプトから1ターン内に複数の行動コマンドが呼び出された場合、**最も最初に実行されたコマンドのみが採用**されます。以降のコマンド呼び出しは無視されます。

---

## 公開API（スクリプト内コンテキスト）

スクリプト実行環境には、以下のグローバル変数、オブジェクト、およびメソッドが事前バインドされています。これら以外のブラウザ標準オブジェクト（`window`, `document` 等）にはアクセスできません。

### 1. プレイヤー状態 (`player`)
プレイヤーキャラクターの現在のステータス情報を提供する読み取り専用オブジェクトです。

| プロパティ名 | 型 | 説明 |
| :--- | :--- | :--- |
| `name` | `string` | プレイヤーキャラクターの名前 |
| `hp` | `number` | 現在のHP |
| `maxHp` | `number` | 最大HP |
| `mp` | `number` | 現在のMP |
| `maxMp` | `number` | 最大MP |
| `attack` | `number` | 攻撃力 |
| `defense` | `number` | 防御力 |
| `level` | `number` | 現在のレベル |
| `exp` | `number` | 現在の経験値 |
| `expToNextLevel` | `number` | 次のレベルに必要な累積経験値 |
| `isAlive` | `boolean` | 生存しているか (`hp > 0`) |
| `hpRate` | `number` | 現在のHP割合（`hp / maxHp`。0.0 〜 1.0） |
| `mpRate` | `number` | 現在のMP割合（`mp / maxMp`。0.0 〜 1.0） |
| `inventory` | `object` | 所持品状態（後述） |

#### メソッド
* **`canAttack()`**: 攻撃に必要なMP（`PlayerActionConstants.ATTACK_MP_COST`）が足りているか判定します。
* **`canHeal()`**: 回復魔法に必要なMP（`PlayerActionConstants.HEAL_MP_COST`）が足りているか判定します。
* **`canDefend()`**: 防御に必要なMP（`PlayerActionConstants.DEFEND_MP_COST`）が足りているか判定します。
* **`canFlee()`**: 逃走に必要なMP（`PlayerActionConstants.ESCAPE_MP_COST`）が足りているか判定します。

---

### 2. インベントリ状態 (`player.inventory`)
プレイヤーが所持しているアイテムとゴールドの状態を管理します。

| プロパティ名 | 型 | 説明 |
| :--- | :--- | :--- |
| `items` | `Array<ReadonlyItemInfo>` | 所持アイテムオブジェクトの読み取り専用リスト |
| `gold` | `number` | 所持ゴールド数 |

#### アイテムオブジェクトの構造 (`ReadonlyItemInfo` / `ReadonlyPotionInfo`)
```typescript
{
  id: string;      // アイテムID
  name: string;    // アイテム名
  type: string;    // アイテム種別 (例: 'potion')
  rarity: string;  // 希少度 ('common', 'rare', 'epic', 'legendary')
  healAmount?: number; // 回復量 (potionの場合のみ存在)
}
```

#### メソッド
* **`getPotions()`**: 所持しているポーション（`type === 'potion'`）のリストのみを抽出して返します。
* **`hasPotion()`**: ポーションを1つ以上所持しているか（`getPotions().length > 0`）を返します。

---

### 3. 敵状態 (`enemy`)
対峙している敵のステータス情報を提供する読み取り専用オブジェクトです（戦闘中のみ存在）。

| プロパティ名 | 型 | 説明 |
| :--- | :--- | :--- |
| `name` | `string` | 敵キャラクターの名前 |
| `type` | `'normal' \| 'leader' \| 'boss'` | 敵のカテゴリランク |
| `hp` | `number` | 現在のHP |
| `maxHp` | `number` | 最大HP |
| `attack` | `number` | 攻撃力 |
| `defense` | `number` | 防御力 |
| `level` | `number` | 敵のレベル |
| `isAlive` | `boolean` | 生存しているか (`hp > 0`) |
| `hpRate` | `number` | 敵の現在のHP割合（`hp / maxHp`。0.0 〜 1.0） |

---

### 4. バトル状態 (`battleState`)
現在の戦闘およびダンジョン探索状況に関するシステムパラメータです。

| プロパティ名 | 型 | 説明 |
| :--- | :--- | :--- |
| `state` | `'idle' \| 'fighting' \| 'victory' \| 'defeat'` | 現在のゲーム・バトル状態 |
| `turnCount` | `number` | 現在の戦闘の経過ターン数（1始まり） |
| `floor` | `number` | 現在探索中のダンジョン階層 |
| `battlesOnCurrentFloor` | `number` | 現在の階層で撃破した戦闘回数 |
| `battlesPerFloor` | `number` | 次の階層に進むために必要な合計戦闘回数 |
| `isPlayerTurn` | `boolean` | プレイヤーの手番か（現在は常に `true`） |

---

### 5. アクションコマンド（行動発行メソッド）
スクリプトがゲームに対して指示を下すためのメソッド群です。呼び出されると、最初の1つだけが実行予定キューに登録されます。

* **`attack()`**: 敵に通常攻撃を行います。
* **`heal()`**: 回復魔法を唱えて自身のHPを回復します。
* **`defend()`**: 防御態勢をとり、被ダメージを軽減します。
* **`flee()`**: 戦闘から逃走を試みます。
* **`useItem(itemId)`**: 指定したIDのポーション等の所持アイテムを使用します。

---

### 6. ユーティリティ・その他
* **`log(message)`**: 指定した文字列メッセージを、デバッグ用のスクリプトログに蓄積します。蓄積されたログは戦闘画面のログコンソールに表示されます。
* **`console.log(message)`**: `log(message)` の別名として機能し、スクリプト実行時ログに蓄積されます。
* **`Math`**: JavaScript 標準の `Math` オブジェクト（`Math.random()`, `Math.floor()`, `Math.max()` 等）をそのまま利用できます。
