# blackjack

## 概要

ブラウザで遊べるシンプルなブラックジャックゲームです。
ベットを行いながらラウンドを進め、所持コインの増減を管理しつつ継続プレイできます。

## 使用技術

- HTML / CSS / JavaScript
- ES Modules
- ビルドツールなしの静的ファイル構成

## 実装の特徴

- アプリ全体を ES Modules で分割し、状態管理・遷移・UI 描画を分離しています。
- ステートマシンベースでラウンド進行を管理しており、局面ごとの振る舞いを整理しやすい構成です。
- ルール処理と DOM 操作を分けた構成になっているため、ゲームロジックを追いやすく保守しやすい実装です。

## 起動方法

`type="module"` を使っているため、ブラウザでファイルを直接開くのではなく静的サーバー経由で起動してください。

```powershell
cd c:\CodeRoot\StaticApps
python -m http.server 8000
```

起動後、`http://localhost:8000/apps/blackjack/` にアクセスします。
