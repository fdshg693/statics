# svelte_baseball

## 概要

Svelte + TypeScript + Vite を前提にした、静的配信向けのシンプルな野球ゲーム案です。
プレイヤーは投手側のみを操作し、1イニング相当の守備を行います。
MVP では、投球コースの選択と、カウントを含む打席結果の進行を主題にします。

このディレクトリには、MVP として遊べるフェーズ 1〜6 の実装と、仕様整理用のドキュメントを配置しています。
実装の詳細や段階的な作業内容は `PLAN.md` および `plan/` 配下を参照してください。

## 使用技術

- Svelte
- TypeScript
- Vite
- HTML / CSS
- 静的ファイル配信を前提とした SPA 構成

## アプリ機能

- 投手として投球コースを選択する
- ボール / ストライク / アウトのカウントを進行する
- 打者はコースごとの確率設定に応じて結果を返す
- 塁状況、得点、アウト数を表示する
- 3アウトでイニング終了とし、結果を表示する
- その場で再プレイできる

## 今回のスコープ外

- 球種の追加
- 打者ごとの個性や詳細な能力差
- 守備操作や送球操作
- 複数イニングや攻守交代
- セーブデータや長期成績の保存
- 派手な演出や詳細なアニメーション

## 設計方針

- ゲームルールと UI を分離し、将来的に調整しやすい構成にする
- コース別の結果確率は、コードに埋め込まず設定データとして扱う
- MVP では依存ライブラリを最小限に抑え、Svelte / Vite / TypeScript を中心に構成する
- 単一画面で完結するシンプルな SPA とし、ルーティングは導入しない

## 起動方法

現在は `Vite + Svelte + TypeScript` の構成が作成されており、以下の流れで起動できます。

### 開発サーバーで起動する想定

```powershell
cd c:\CodeRoot\StaticApps\apps\svelte_baseball
npm install
npm run dev
```

### ビルドして静的配信する想定

```powershell
cd c:\CodeRoot\StaticApps\apps\svelte_baseball
npm run build
```

ビルド成果物は `dist/` に出力し、シンプルな静的サーバーから配信する想定です。
