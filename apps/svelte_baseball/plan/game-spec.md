# Game Spec

## 目的

MVP で扱う野球ルールを最小限に絞りつつ、カウント制を含む標準寄りの進行を成立させます。
プレイヤーは投手として投球コースのみを決め、打者の反応は確率テーブルで決定します。

## ゲームの前提

- プレイヤーは守備側の投手を担当する
- 1回表や1回裏のような片側の守備を、ここでは 1 イニング相当として扱う
- 3アウトでゲーム終了
- 毎球、プレイヤーは投球コースを 1 つ選ぶ
- 打者結果は CPU が確率的に決定する

## コース選択

初期案では、ストライクゾーン周辺を含む `3 x 3` の離散グリッドを使います。
これにより、MVP の段階でも以下の意図を表現しやすくします。

- 真ん中寄りのコースは打者にとって好結果が出やすい
- 端や外寄りのコースは打者にとって好結果が出にくい
- 将来は球種や高低差、打者タイプ補正を追加しやすい

## 1 球ごとの結果カテゴリ

各投球では、少なくとも以下のカテゴリのいずれかが発生します。

- ボール
- 見逃しストライク
- 空振りストライク
- ファウル
- インプレーアウト
- 単打
- 二塁打
- 三塁打
- 本塁打

MVP では、結果カテゴリ自体はコース依存で判定し、カウント依存の細かな補正は後回しにします。

## カウント進行

- ボールは `4` で四球
- ストライクは `3` で三振
- ファウルは 2 ストライク未満ならストライク加算
- 2 ストライク時のファウルでは三振にしない
- インプレー結果が発生した場合、その打席のカウントはリセットする

## インプレー時の扱い

MVP では、進塁処理を分かりやすい固定ルールで扱います。
打球方向や守備位置までは扱わず、結果カテゴリごとに進塁結果を確定させます。

初期ルール案:

- インプレーアウト: 1 アウト追加、走者は原則据え置き
- 単打: 打者は一塁、既存走者は基本的に 1 つ進む。三塁走者は生還
- 二塁打: 打者は二塁、二塁と三塁の走者は生還、一塁走者は三塁へ進塁
- 三塁打: 打者は三塁、走者は全員生還
- 本塁打: 打者を含め全員生還

この進塁ルールは MVP 向けの簡略版であり、将来は走者速度や打球内容に応じた拡張を想定します。

## 表示したい情報

- 現在のボール数 / ストライク数 / アウト数
- 塁状況
- 現在得点
- 直前の投球コース
- 直前の結果
- イニング終了時の最終得点

## MVP では扱わないもの

- 球種
- 打者ごとの打撃傾向
- 守備シフト
- 盗塁、暴投、牽制
- 犠打、併殺、失策
- 複数イニングの進行

## 拡張前提

将来の拡張に備え、以下は設定や追加ロジックで差し込める設計を前提にします。

- コースごとの確率テーブル
- カウントによる補正
- 打者タイプや難易度による補正
- 球種ごとの結果変化
