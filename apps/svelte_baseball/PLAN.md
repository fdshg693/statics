# svelte_baseball PLAN

## このファイルの役割

`PLAN.md` には、アプリ全体の目的、現在の意思決定、詳細ドキュメントの導線だけをまとめます。
実装手順や細かな仕様は巨大化を避けるため、`plan/` 配下に分割して管理します。

## ゴール

- Svelte で作る、静的配信可能なシンプルな野球ゲームにする
- プレイヤーは投手側のみを担当し、1イニング相当の守備をプレイできるようにする
- 投球コース選択と、コースに応じた確率的な打席結果をゲームの中心に置く
- MVP の時点でカウント、走者、得点、アウトを扱い、最低限の野球らしさを成立させる
- 将来的に球種、打者タイプ、難易度などを拡張しやすい構成にする

## 現時点での決定事項

- 技術構成は `Vite + Svelte + TypeScript`
- アプリ形態は単一画面の SPA
- ビルド後は `dist/` を静的ファイルとして配信する
- MVP ではボール / ストライク / 四球 / 三振 / インプレー結果を扱う
- プレイヤーが操作するのは投球コースのみ
- 打者の結果は、主にコース別の確率設定で決める
- 依存ライブラリはできるだけ増やさない

## 全体像

本アプリは、投球コースを選ぶ UI と、野球ルールを判定するゲームロジックを分離して設計します。
まずは 1 打席ごとの結果を積み上げて 3 アウトまで進める構成にし、演出よりもルールの見通しと拡張性を優先します。

コース選択は離散的なゾーン選択で始め、真ん中ほど打者に有利、際どいコースほど投手に有利という確率傾向を持たせます。
ただし MVP の段階では、細かなパラメータの作り込みよりも、設定データを差し替え可能な形で保持することを優先します。

## 進め方の方針

実装時は、まずゲーム仕様と技術選定を固定し、その後に状態管理、結果判定、UI、ビルド確認の順で積み上げます。
詳細なステップは `plan/implementation-phases.md` に切り出して管理します。
